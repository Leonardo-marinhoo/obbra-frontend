# Obbra Frontend

Protótipo funcional de diário de obras com React, TypeScript e Vite.

## Recursos

- Dashboard responsivo
- Cadastro e acompanhamento de obras
- Diário com clima, equipe, atividades e ocorrências
- Fotos armazenadas como Blob no IndexedDB
- Dados da aplicação no localStorage
- Backup local em JSON
- Sem login e sem backend nesta primeira etapa

## Rodar e validar

```bash
npm install
npm run dev
npm run lint
npm run build
```

> Os dados ficam apenas no navegador atual. Limpar os dados do site remove os registros locais.
